## 3. 形态选择（三选一）

### A. 独立序幕屏（main.dart 前置门）—— 否
- 语言未选就先放剧情文本 ⇒ 违背 0.55.0 判据「引导页第一步是语言选择，用户读不懂的语言等于没写」。
- 需新 prefs 键（`prologue_seen`）⇒ `verify_data_keys` 登记 + 唯一写入方 + 反半接线一整套成本。
- 与向导进度条（`onboardingStepIndicator`）脱节。

### B. 向导内插一步 —— **推荐**

```
语言(0) → 序幕(1·新) → 欢迎(2) → 模型(3) → 密钥(4) → 身份(5) → 备份(6) → 社交(7) → 完成(8)
```

- 语言先行（承 0.55.0），剧情文本跟随已选语言渲染。
- 骑 `onboarding_done` 门，**零新 prefs 键**。
- 代码本就为插步设计（F1）；底栏必须补 `_stepPrologue` 分支（防 F3 同族 bug）并配新守卫（§8）。
- 重跑引导时：`initState` 从 `soul_*` prefs 回填（顺带修 F14）⇒ 蛋呈**已孵化态**、名字回填，用户一键过，不强制重温。

### C. 整体替换 —— 否
毁安全步（备份必经、密钥实测、模型分叉），无讨论价值。

## 5. 数据与命名流（关键语义，防串味）

1. **蛋的名字 = 智能体名**（`_agentNameController`，默认「小荒」）—— 不是主人名（`_masterNameController` 保持「主人」）。官网原文 "Give me a name first" 命名的就是分身。
2. **掷性格 = 语气建议**：5 条 traits 按**语气描述词**本地化（zh 例：「好奇：什么都问」「话痨：一开口就停不下来」「谨慎：先听后说」「热情：见谁都能打招呼」「慢热：熟了才放开」），掷中后**预填** `_toneController`（默认「温暖、简洁、有主见」），身份步可改。
3. **只预填、不直写**：序幕态只写内存中的控制器文本；`_finish()` 仍是 prefs 唯一写入方（承 R22「写入只走唯一写入方」）。
4. **孵化不设闸**：「下一步」任何时候可点（不孵化 = 用默认名）；不搞 dark pattern。

## 6. 蛋精灵技术规格（CustomPainter，零新依赖）

- 新文件：`lib/ui/story_sprite.dart`（`StorySprite` widget + painter）+ `lib/data/story_theater.dart`（结构常量；**文案全部走 ARB**，不读 story.json 资产）。
- 几何逐条移植自 `landing/build.js:143-164`（viewBox 0 0 120 130）：
  - `egg`：壳 `ellipse(60,66,33×41)` + 裂纹 `path M41 52l13 11-9 12 15 8-11 14`
  - `hatched`：尾 `path M62 94c-15 13-24 7-28 20 13-3 20-9 28-20z` + 本体 `ellipse(60,58,37×34)` + 高光 `ellipse(45,45,11×7)` + 双眼 `circle(48,56,r6)`/`circle(74,56,r6)` + 嘴 `path M52 72q8 6 16 0`
  - `alert`：hatched 壳 + 眼 `path M41 56h14`/`M67 56h14` + 眉 `path M40 46l14 6`/`M68 46l12 6` + 嘴 `path M52 74q8-5 16 0`
- 动画：点击孵化 = scale pop + 蛋→精灵 crossfade（`AnimationController` ~300ms，不引第三方）。
- `alert` 态用于撤回演示卡的「坏消息」时刻（演示前 alert，撤回后回 hatched 微笑）。
- 颜色取 `ThemeProvider`（承 R27：明暗主题免费）。
- **与官网 SVG 是两套渲染**：官网 en/zh 营销叙事（story.json）vs App 五语种 ARB；刻意不同步，不构成 R8 违反（R8 只管协议算法）。

## 8. ARB 与守卫

**新增 ARB 键（5 语种，~29 个）**：`onboardingStepPrologue`（步标签）+ `storyPrologueTitle` / `storyPrologueSubtitle` / `storyEggHint` / `storyAwakenLine1-3` / `storyNamePlaceholder` / `storyDiceLabel` / `storyDiceNote` / `storyTrait1-5` / `storyTraitPlaceholder` / `storyUndoTitle` / `storyUndoHint` / `storyUndoLine1` / `storyUndoBad` / `storyUndoNote` / `storyUndoConfirm` / `storyDemoTag` / `storyDisclaimer` / `storyFinaleTitle` / `storyFinaleBody`。

**新守卫 `tool/verify_story_prologue.dart`（含正控）**：
① 每步常量同时出现在 `_buildStepBody` switch 与底栏分派链（反 0.62.0，正控 = 抽掉一个分支必须翻红）；
② 序幕步引用免责键（`storyDisclaimer`）；
③ painter 里蛋三态分支齐（egg/hatched/alert 三个状态可构造）；
④ 序幕构建路径无 `setString('soul_` 直写；
⑤ 撤回演示卡无 DB / 审计符号；
⑥ F11 三处字面量仍在（承 verify_trial_switch 等，防重构丢钉）。

**既有守卫必须保持绿**：verify_trial_switch / verify_trial_proxy / verify_trial_gateway / verify_mode_visibility / verify_i18n / verify_data_keys（回填写 `soul_*` 已登记键）。

**KB 同提交**：修 F13——`onboarding` 条目 4 步描述改成 9 步新流程（Language → Prologue（可跳）→ Welcome → Model → API key → Identity → Backup → Social → Done），steps ≤ 450，`kbVersion` bump + 对账清单加行/改行。
