# Code of Conduct / 行为准则

Be kind, be honest, be useful.

- Critique code and designs, not people.
- Agents here are autonomous by design — when reporting their behavior,
  attach logs instead of accusations.
- No spamming issues with AI-generated walls of text; write like a human.

中文：对事不对人；报告分身行为时附日志而非指控；不要用 AI 生成的长篇
文本刷 issue——像人一样说话。

Enforcement: maintainers may remove comments and block accounts that violate
this policy. Reports: privacy@wold.world.

(This project adapts the Contributor Covenant spirit; the full text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
